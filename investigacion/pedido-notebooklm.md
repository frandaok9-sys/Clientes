# Pedido para la sesión local (Claude in Chrome + NotebookLM)

Pegá este texto entero en la sesión de Claude Code de tu computadora que tiene Chrome conectado.

---

Necesito que investigues en NotebookLM para la prospección de COI (CRM-ERP en la nube para PyMEs industriales argentinas). NotebookLM está abierto en Chrome.

1. Con Claude in Chrome, abrí la pestaña de NotebookLM y listá qué cuadernos y fuentes hay.
2. En el cuaderno relevante, hacé estas consultas y copiá las respuestas textuales con las fuentes que cite:
   1. ¿Cuál es el cliente ideal de COI (rubro, tamaño, cantidad de usuarios, zona)? ¿Hay datos que confirmen o cambien este borrador: PyME industrial B2B, 10–100 empleados, 3–30 usuarios, Argentina?
   2. ¿Qué rubros industriales tienen más potencial y por qué? ¿Qué dolores concretos tiene cada uno?
   3. ¿Qué objeciones típicas aparecen y cómo se responden?
   4. ¿Qué argumentos o frases de venta funcionan mejor?
   5. ¿Qué sistemas usan hoy estas empresas (Tango, Xubio, Colppy, planillas...)? ¿Qué competidores aparecen?
   6. ¿Se mencionan listas, directorios, cámaras o fuentes públicas de empresas?
   7. Cualquier otro dato útil para calificar o contactar empresas.
   No inventes nada: si NotebookLM no tiene la respuesta, anotá "sin datos".
3. Guardá todo en `investigacion/notebooklm.md` del repo frandaok9-sys/Clientes, en la rama
   `claude/customer-classification-prospecting-uxgdbb` (primero `git pull`), y hacé commit y push.
   Si no tenés el repo clonado, clonalo; y si no podés hacer push, dejame el archivo listo y avisame.
